        TEXT

        This document specifies cybersecurity requirements for Class 0 vehicle systems: Telematics, Fleet Management Information Systems (FMIS), and Electronic Logging Devices (ELDs).

        Telematics systems deployed in commercial motor vehicles are distributed systems that encompass multiple distinct components rather than a single isolated ECU. To provide clear evaluation boundaries and support modular procurement, Class 0 decomposes a telematics system into four architectural components:

        1. Vehicle Connection Component: The physical hardware device connected directly to vehicle communication networks (e.g. CAN, J1939, Ethernet, RP1226, or trailer interfaces). This on-vehicle device satisfies hardware, network bus, diagnostic, and interface security controls.
        2. Connectivity or Communications Component: The cellular, satellite, Wi-Fi, BLE, or wide area communications pipeline that transfers data between the vehicle and off-vehicle systems. In systems where wireless connectivity is housed in the same physical enclosure as the vehicle connection interface, both the Vehicle Connection and Connectivity requirements apply to that hardware unit. In systems where the vehicle unit bridges via a driver smartphone/tablet hotspot, the connectivity requirements apply to that communications path.
        3. Cloud or Back-End Component: The server, cloud, and hosting infrastructure where telemetry and fleet data are collected, stored, and analyzed, where remote commands or vehicle updates originate, and where web portals or fleet management dashboards operate.
        4. Mobile App or Driver Interface Component: The human-machine interface (HMI), smartphone/tablet mobile application, or dedicated cab display presented to drivers or maintenance operators.

        Instructions for Preparing and Responding to Questionnaires:

        • Evaluate All Telematics Systems: A single tractor or trailer may incorporate multiple telematics systems (e.g., OEM factory gateway, aftermarket ELD/FMIS, powertrain telematics, camera/vision safety subsystems). A complete vehicle assessment requires separate responses for each distinct telematics system present.
        • Component-Specific Sheets: The supplier questionnaire for Class 0 provides dedicated worksheets for each of the four components: - Class 0 - Vehicle Connection - Class 0 - Connectivity - Class 0 - Cloud Back-end - Class 0 - Mobile App
        • Distributed Responsibilities: OEMs, suppliers, and procurement teams should route the respective component questionnaires to the responsible engineering teams (e.g., hardware/firmware engineers for Vehicle Connection, mobile developers for the Mobile App, cloud DevOps for the Back-End).
