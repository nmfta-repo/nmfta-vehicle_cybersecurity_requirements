        TEXT

        This document specifies cybersecurity requirements for Class 7 vehicle components: Single Segment Low Risk.

        Class 7 devices are truck modules connected to a single vehicle network segment found to have a low overall fleet risk.

        Examples include: - Electric Propulsion Control Unit #1 - Retarder Display (J1939 SA 23) - Shift Console - Secondary (J1939 SA 06) - Transmission Display - Secondary (J1939 SA 60) - Chassis Controller #1 / SAM Chassis (J1939 SA 71) - Passenger-Operator Climate Control #1 / LECM / HVAC (J1939 SA 25) - Battery Pack Monitor #1 (J1939 SA 243) - Slope Sensor / Hill Start Assist - Aftertreatment #1 / #2 system gas outlet / NOx sensors (J1939 SA 82, 87) - Axle - Steering (J1939 SA 08) - Steering Column Unit / Turn Signal Control - Steering Wheel Switches (J1939 SA 77) - Auxiliary Valve Control / Engine Air System Valve Control (J1939 SA 34) - Catalyst Fluid Sensor / DEF Quality Sensor (J1939 SA 211) - Seat Control #1 - Turbocharger, Wastegate, Compressor Bypass (J1939 SA 02) - Door Controller / Door Controllers #1-#4 (J1939 SA 236, 237) - Engine Exhaust Gas Recirculation (J1939 SA 70) - Cab Display #1 - Vehicle Security (J1939 SA 29)
