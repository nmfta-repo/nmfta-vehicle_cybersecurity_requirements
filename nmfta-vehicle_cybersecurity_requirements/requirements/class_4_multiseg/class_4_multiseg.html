    • Class 4 Multi Segment Security Requirements

    STATEMENT:

    This document specifies cybersecurity requirements for Class 4 vehicle components: Multi Segment.

    Class 4 devices are truck modules that are not intended to be Vehicle Gateways but nonetheless are connected to two or more vehicle network segments where all of the segments are trusted (internal closed vehicle subnets).

    Examples include: - Steering Controller (Front Axle Steering / FAS / VDS / MCS) (J1939 SA 19) - Electronic Clutch Actuator (J1939 SA 03) - Headway Controller (J1939 SA 42) - Engine Injection Control Module (J1939 SA 00) - Chassis Controller #2 (J1939 SA 72) - Transmission Display Primary (J1939 SA 59) - Switch Field (Modular Switch Field / MSF) (J1939 SA 138)
