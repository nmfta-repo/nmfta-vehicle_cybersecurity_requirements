        TEXT

        This document specifies cybersecurity requirements for Class 2 vehicle components: Vehicle Gateway.

        Class 2 devices are truck modules intended to perform gateway functions (transport, translate, transform, filter, or encapsulate data) between two or more vehicle network segments.

        Examples include: - Onboard Diagnostics Connector Gateway (Central Gateway / CGW) (J1939 SA 39, 17, 44, 49, 50, 77) - 3rd Party Equipment Gateway (J1939 SA 249) - Telematics Interface Gateway
