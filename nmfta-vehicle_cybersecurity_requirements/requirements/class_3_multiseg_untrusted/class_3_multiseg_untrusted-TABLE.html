        TEXT

        This document specifies cybersecurity requirements for Class 3 vehicle components: Multi Segment with Untrusted Wired Connection.

        Class 3 devices are truck modules that are not intended to be Vehicle Gateways but nonetheless are connected to two or more vehicle network segments where one or more of those segments are untrusted (e.g. diagnostic ports, trailer bridges, or networks exposed to external physical connections).

        Examples include: - Tractor/Trailer Bridge #1 / #2 (J1939 SA 32, 138, 39) - Powertrain Control Module (CPC) (J1939 SA 90) - Engine #1 (MCM / EMS / ECM) (J1939 SA 00, 01) - Transmission #1 (TCM) (J1939 SA 03) - Cab Controller Primary / Secondary (SAM CAB) (J1939 SA 49, 50) - Instrument Cluster #1 (Gauges) (J1939 SA 23) - On Board Diagnostic Unit (J1939 SA 250) - ADAS Adaptive Cruise Control / Lane Keep (Bendix Fusion) (J1939 SA 42, 232, 19)
